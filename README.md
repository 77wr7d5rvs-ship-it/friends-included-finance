# Friends Included · Finance Desk

Node.js finance system for the Friends Included Day 4 homework brief.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000`.

The app includes the completed two-test fictional records, role selector, transaction forms, manager controls, calculations, and links for Telegram, Google Sheets, and GitHub. Server-side integration variables belong in Vercel environment settings; never commit tokens or service-account credentials.
